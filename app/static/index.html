          検査

          コードが模型を調べた結果です。会社ルールや図面と比べた結果と、部品ごとの形・大きさを並べます。黄と赤の印が付いた行は、確かめる所です。

            書き出し

            3D プリンターに送るファイルです。ふつうは、いちばん上の 3MF（Bambu Studio 形式）を保存して開きます。

              Bambu Studio で開くとき

              「Bambu Studio 形式」の 3MF を開くと、外壁の部品にだけファジースキン（外側の輪郭）が設定されています。ファジースキンは形には出ません。スライスしてプレビューで外壁を拡大すると、線が細かく波打って見えます。
              ふつうの形式の 3MF は形だけ読まれるので、外壁の部品（1階の外壁・屋根の外壁）を選び、「その他」→「ファジースキン」→「外側の輪郭」にしてください。2つ目以降のパーツはプレートの外に置いてあります。プレートを足して「並べる」で配置してください。

              設定

              ここで変えた設定は、この PC の HAKOYA 全体に効きます（物件ごとではありません）。

              見え方

              上の帯の右で切り替えます。見本確認用＝審査・動画用（見本の家だけ・手順の帯）。自社利用用＝全部の機能。他社利用用＝ほかの会社で使う形（AI は API キーと AI なしだけ）。

              物件の登録

              Walk in home の glb（と図面のフォルダ）を選び、仮名を付けて登録します。元のファイルは読むだけで、書き換えもコピーもしません。ファイル名や場所（施主名が入ることがあります）は画面に出しません。
              ふだんは glb だけで組み立て・検査・検品します。「高性能読み込み」を入にした物件だけ、図面とも突き合わせます（窓の注記の照合・平面図に図面を重ねる・図面を見せた検品）。スキャンした PDF は読めません。

              会社ルール

              あなたの会社の決まりを選んでください。まだ選んでいないときは、B工務店（架空）の決まりで組み立てます。

              「読み込んで組み立てる」で使う会社の決まり（壁の厚み・屋根板の出・外壁の仕上げ・標準の高さ・検品の考え方）。切り替えたあと、物件を選んで「読み込んで組み立てる」を押すと、その会社の決まりで作り直します。B工務店は、会社ごとに切り替えられることを見せるための架空の会社です。

              組み立てたあとの検品

              「読み込んで組み立てる」のあと、自動で検品を始めます。Claude（自分のプラン）はプランの利用枠を、Claude（API キー）はキーの持ち主の料金を使います。

              API キー（「API キーで検品する」に使う）

              キーは Windows の資格情報マネージャーに保存します。画面・ファイル・記録には出しません。
              API キーで検品すると、キーの持ち主に Claude の API の料金がかかります。1回の上限は rules/ai_models.yaml の max_budget_usd（いまは $3.00）で、超えそうになると止まります。

              会社ルール

              家・会社によって変わる値（窓の高さ・屋根の勾配など）は、物件ごとに glb から作ります。物件によらず同じ値（壁厚など）と細かい決まりを「会社ルール」として残し、困ったとき（glb が読めない・いつもと違う・新しい形）の予防に使います。
