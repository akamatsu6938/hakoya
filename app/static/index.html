                    読み込むものについて

                    Walk in home の glb（と図面のフォルダ）を選び、仮名を付けて読み込みます。元のファイルは読むだけで、書き換えもコピーもしません。ファイル名や場所（施主名が入ることがあります）は画面に出しません。

                    図面は jww か、jww・Walk in home から書き出した文字を選べる PDF。名前の「平面」「立面」「断面」「2階」で種類を分けます。ふだんは glb だけで組み立て・検査・検品します。「高性能読み込み」（環境設定の物件の一覧）を入にした物件だけ、図面とも突き合わせます。スキャンした PDF は読めません。

                    環境設定

                    ここで変えた設定は、この PC の HAKOYA 全体に効きます（物件ごとではありません）。

                    AI のつなぎ方

                      API キー（「API キーで検品する」に使う）

                      キーは Windows の資格情報マネージャーに保存します。画面・ファイル・記録には出しません。API キーで検品すると、キーの持ち主に Claude の API の料金がかかります。1回の上限は rules/ai_models.yaml の max_budget_usd（いまは $3.00）で、超えそうになると止まります。

                      組み立てたあとの検品

                      「読み込み直す」のあと、自動で検品を始めます。Claude（自分のプラン）はプランの利用枠を、Claude（API キー）はキーの持ち主の料金を使います。

                      会社ルール

                      あなたの会社の決まりを選んでください。まだ選んでいないときは、B工務店（架空）の決まりで組み立てます。

                      「読み込み直す」で使う会社の決まり（壁の厚み・屋根板の出・外壁の仕上げ・標準の高さ・検品の考え方）。切り替えたあと、物件を開いて「読み込み直す」を押すと、その会社の決まりで作り直します。B工務店は、会社ごとに切り替えられることを見せるための架空の会社です。

                      物件の一覧

                      ふだんは glb だけで組み立て・検査・検品します。「高性能読み込み」を入にした物件だけ、図面とも突き合わせます（窓の注記の照合・平面図に図面を重ねる・図面を見せた検品）。
