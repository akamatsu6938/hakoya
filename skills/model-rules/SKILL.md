# 模型として成り立たせるルール（考え方）

数値は会社ルールの `model` の項目にある（`scale`・`min_feature_mm`・`corner_block_*`・`fit_clearance_mm` など）。

## パーツの分け方
- 平屋は「基礎」「1階（床・内壁＋外壁。天井の高さまで）」「屋根（屋根板・天井より上の外壁・ポーチの天井）」（会社ルールの `model.split_at_ceiling`）。屋根（2階建てなら2階も）を外すと、中の壁がすべて見えることがいちばん大事。
- 外壁の外の面の薄い層（`model.fuzzy_skin_band_mm`）だけを別の部品にして、ファジースキン（外側の輪郭だけ）でざらざらにする。窓の高さでは外壁の輪が途切れ、細い柱の全周がざらざらになってしまうため、表面だけに限り、窓・ドアのまわりは外す。
- 2階建て（下屋あり）は5つ：「基礎」「1階」「下屋の屋根」「2階」「大屋根」。下屋の屋根と2階は別の部品で、別々に持ち上げられる。わざとこう作っているので、指摘しない：
  - 2階の下の1階の壁は2階の床板の裏まで、下屋の下の1階の壁は1階の天井まで（高さに段がある）。下屋の下の天井より上の外壁（三角形の飾り壁）は下屋の屋根の部品にある。
  - 2階の外壁は床板の裏から。glb で下屋の屋根の上から始まる2階の南の壁は、床板の裏まで下ろしている（下屋の屋根裏に隠れる）。
  - 下屋の屋根板は2階の外形の所を除き、2階の外壁と隙間を空けている。ずれ止めは1階の角だけ。
  - 2階の一部が屋外（ポーチ）の上に出ている所は、1階の部品に、ポーチの天井から2階の床板の裏までの塊として作っている（サポート材で印刷）。
  - 階段・手すり壁は造作なので作らない。2階の床板には階段の穴がある。
- 検品用の模型の立面図では、開口をガラスの色で塗っている（glb の図と見比べるため）。
- 地面は印刷しない（発泡スチロールで敷地に合わせて作る）。色は付けない（印刷後に絵の具で塗る）。

## 印刷できる太さ
- 枠・桟・壁は `min_feature_mm` より細くしない。開口の上（下）に残る壁が細すぎるときは、上（下）まで切り抜く（室内ドアは天井まで抜けることが多い）。
- 浮いた部材（どこにもつながっていない塊）はできない。印刷では同じオブジェクトの部品は一体になる。

## 窓の上の帯（壁ごとの `lintel_band_mm`）
- 外壁は天井の高さで分けるので、窓・ドアの上端が天井の高さに届くと、窓の上の壁は屋根の部品に入る。窓が並ぶ外壁では、窓の間の細い柱が1階の部品の中で下だけでつながり、印刷・組み立てで折れやすい。
- 直す案は「窓の上に帯を残す」：target=その外壁、field=`lintel_band_mm`、value_source=`rule:model.lintel_band_mm`（数値はコードが会社ルールから出す）。並びの上だけ、1階の外壁を「いちばん高い上端＋帯」まで残し、屋根の部品の外壁から同じ所を除く（重ならない）。ずれ止めの三角の近くは帯を止める。
- 案を出すのは、平屋で、上端が天井の高さに届く窓・ドアが2つ以上並び、間に柱（幅が高さより細い壁）がある外壁だけ。コードの検査がすでに同じ案を出していれば、重ねて出さない。帯がすでにある壁（`lintel_band_mm` が 0 より大きい）、2階建ての家には出さない（2階建てはまだ作れない）。
- 天井の高さに継ぎ目が出ること自体は正しい（指摘しない）。指摘するのは、その継ぎ目のせいで窓の間の柱の上がつながらないことだけ。帯を付けた壁では、帯の所だけ継ぎ目が上にずれて段になるのも正しい。

## ずれ止め（隅の三角ブロック）
- 社内の紙の模型と同じ作り。外すパーツ（屋根）の裏の、外壁の内側の角に三角を付け、下の壁の内側の角にはめる。四隅に近い角を最低4か所。
- 屋根は面ごとに分け、上の面を床に付けて印刷する（片流れは分けない）。三角は屋根の勾配だけ傾いて上に立ち、支えなしで印刷できる。
- 基礎と1階は、基礎の帯の内側の角に上向きの三角、1階の床裏に受けのくぼみ。
- はめあいの隙間は `fit_clearance_mm`。試験片で詰める。

## 印刷の向きと気をつける形
- 本体（1階）は床を下。屋根は棟・隅棟・谷の線で面ごとに分け、上の面を床に付けて置く（のりで付ける所は棟・隅棟）。ポーチの天井の板は屋根と一緒に斜めになり、見えない側にサポートが要る。
- 床から離れて水平に渡る形（下がり壁など）は「橋渡し」になる。長いと垂れるので、指摘の対象。
- 造形範囲（Bambu Lab A1 は 256mm 角）を超えるパーツは分け方を考える。

## 検品で見るときの目安
- 閉じた立体でない・浮いた塊がある・造形範囲を超える → 重要度「高」。
- 細すぎる所・長い橋渡し・三角がはまらない所 → 重要度「中」。
