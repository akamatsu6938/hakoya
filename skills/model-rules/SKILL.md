# 模型として成り立たせるルール（考え方）

数値は会社ルールの `model` の項目にある（`scale`・`min_feature_mm`・`corner_block_*`・`fit_clearance_mm` など）。

## パーツの分け方
- 平屋は「基礎」「1階（床・内壁＋外壁）」「屋根」「ポーチの天井」。屋根（2階建てなら2階も）を外すと、中の壁がすべて見えることがいちばん大事。
- 外壁は1階と同じオブジェクトの別の部品にする。外壁だけファジースキン（外側の輪郭だけ）でざらざらにするため。窓の枠は外壁の部品に入れない（枠までざらざらになるため）。
- 地面は印刷しない（発泡スチロールで敷地に合わせて作る）。色は付けない（印刷後に絵の具で塗る）。

## 印刷できる太さ
- 枠・桟・壁は `min_feature_mm` より細くしない。開口の上（下）に残る壁が細すぎるときは、上（下）まで切り抜く（室内ドアは天井まで抜けることが多い）。
- 浮いた部材（どこにもつながっていない塊）はできない。印刷では同じオブジェクトの部品は一体になる。

## ずれ止め（隅の三角ブロック）
- 社内の紙の模型と同じ作り。外すパーツ（屋根）の裏の、外壁の内側の角に三角を付け、下の壁の内側の角にはめる。四隅に近い角を最低4か所。
- 屋根は裏返して印刷するので、三角は上向きになり、支えなしで印刷できる。
- 基礎と1階は、基礎の帯の内側の角に上向きの三角、1階の床裏に受けのくぼみ。
- はめあいの隙間は `fit_clearance_mm`。試験片で詰める。

## 印刷の向きと気をつける形
- 本体（1階）は床を下、屋根は裏返し、ポーチの天井は平らに置く。
- 床から離れて水平に渡る形（下がり壁など）は「橋渡し」になる。長いと垂れるので、指摘の対象。
- 造形範囲（Bambu Lab A1 は 256mm 角）を超えるパーツは分け方を考える。

## 検品で見るときの目安
- 閉じた立体でない・浮いた塊がある・造形範囲を超える → 重要度「高」。
- 細すぎる所・長い橋渡し・三角がはまらない所 → 重要度「中」。
