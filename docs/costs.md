→ **アプリの AI を動かしたら、ここに1行足す**（値はアプリが書く記録（findings.json・lasso_log.jsonl など）の cost_usd・時間から。推測で書かない）。

## 読み方
- **API キー**：使った分だけ請求される（従量課金）。金額はトークン数 × 公式の料金表（rules/ai_models.yaml、2026-11-04 に公式の料金表で確認）。
- **プラン（Claude のログイン）**：Max などの月額の中で使う。1回ごとの請求はない。表の金額は Agent SDK が出す「API に換算した目安」で、プランの使える量をどれだけ使ったかの目安。
- 料金（100万トークンあたり、2026-11-04 公式）：Opus 5.5 入力 $4・出力 $20、Sonnet 5.5 入力 $2・出力 $10、Haiku 5.5 入力 $0.10・出力 $0.50。覚えさせた指示の読み直しは Opus・Sonnet で入力の 0.05 倍。まとめて送る（Batch）と半額。

## 運用の目安（11/4 時点の概算。物件が増えたら直す）
- **1棟あたり（API キー）**：検品1回 約 $0.3 ＋ 囲んで直す 3〜5回 × 約 $0.05〜0.2 ＝ **約 $0.5〜1.3**（推定。囲んで直すの API キーでの実測はまだ）。
- **1棟あたり（全部 Opus で検品した場合の目安）**：検品1回 約 $2〜2.9 ＋ 囲んで直す ＝ 約 $2.5〜4（プランでの目安から）。
- **月あたり**：月 10棟なら API キーで約 $5〜13、月 30棟なら約 $15〜40（推定）。為替は別。
- AI を使わない「コードの検査だけ」は無料（何度でも）。
- (要検証) 囲んで直す・会社ルールの言語化を API キーで動かした実測。検品を Sonnet にしたときに見落としが増えないか（わざと間違いの試験は Opus だけで測った）。
