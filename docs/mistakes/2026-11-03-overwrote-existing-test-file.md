# 2026-11-03 新しいテストで、同じ名前の既存のテストファイルを上書きした

## 何が起きたか
- 「表で直す：階高」のテストを `tests/test_levels.py` という名前で新しく書いた。
- 同じ名前のファイル（高さの決め方 detect_levels のテスト）がすでにあり、中身を丸ごと置き換えていた。
- テストの数が 210 → 207＋新しい9件 になっていたことで気づいた（コミットの前）。

## 原因
- 新しいファイルを書く前に、同じ名前のファイルがあるかを確かめなかった。
- 書き込みの道具は、読んだことのあるファイルなら確かめずに上書きする（この会話の前半で読んでいた）。

## 直したこと
- git から元の `tests/test_levels.py` を戻し、新しいテストは `tests/test_level_edits.py` に移した。テスト 219 件合格。

## 次から
- 新しいファイルを作るときは、先に同じ名前がないかを調べる（Glob）。
- テストを足したら、テストの数が「前の数＋足した数」になっているかを見る。
