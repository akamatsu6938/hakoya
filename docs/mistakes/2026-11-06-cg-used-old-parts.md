# 動画の CG が、形を直す前の古い部品のままだった（2026-11-06）

## 何が起きたか
- 11/5 夜に、袖壁（家の外の単独の壁）を屋根の部品から1階の部品へ移す直しを入れた。
- 動画の題字の所の CG（屋根が外れる・載る演出）、冒頭の CG、印刷の CG は、その前（11/5 夕方）に書き出した部品で作っていた。
- そのため、屋根を外すと袖壁が一緒に持ち上がって見えた。下書き6まで気づかず、作者が見つけた。

## なぜ起きたか
- 画面の録画は、直したあと（11/6 朝）に撮り直した。しかし CG は「見た目の演出」と考えて、元の部品を作り直さなかった。
- 下書きを確かめるとき、題字の所は字（HAKOYA）だけを見て、部品の形（どの壁が屋根と一緒に動くか）は見ていなかった。

## どう直したか
- 直したあとの部品（11/6 に B工務店で組み立て直したもの）で、部品を使う CG を3本とも作り直した（下書き7）。
- 屋根が外れている間、袖壁が家の側に残るのを、コマを取り出して確かめた。

## 次に気をつけること
- 模型の形（部品の分け方・壁・屋根）を変える直しを入れたら、その部品を使う絵（CG・録画・説明の絵）を全部洗い出して作り直す。
- CG の道具の元の部品のフォルダと、書き出した日時を、下書きの報告に必ず書く。
- 下書きを確かめるときは、字だけでなく、直した所（今回は袖壁）が絵の中でどう動くかを見る。
